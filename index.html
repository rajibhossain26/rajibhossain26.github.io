us-tree-canopy-change

View project →

How has US tree canopy changed since the mid-1980s? County means from 30 m USFS/NLCD Tree Canopy Cover rasters, about 15 billion pixels a year, computed in GitHub Actions. Four in five counties gained canopy, led by the Southeast, while ten western states lost it, with the steepest county losses in wildfire areas. Moran's I shows the changes are strongly clustered (I = 0.69).

georgia-health-atlas

View project →

Where do chronic disease and unmet social needs cluster in Georgia? Using CDC PLACES 2025 data for all 159 counties in a SQL database, global and local Moran's I find 37 hot-spot counties in rural southwest and east-central Georgia, home to about 597,000 people, where adult diabetes averages 15.3% compared with 11.2% in the metro-north cold spot.

healthcare-access

View code →

A Python package, published on PyPI (pip install healthcare-access), that measures how many doctors people can actually reach. It implements 2SFCA, Enhanced, Gaussian, Modified and Three-step FCA and gravity models with OpenStreetMap drive times and population-weighted equity metrics, and is covered by automated tests.

urban-heat-equity

View code →

Who lives in the hottest, least green neighborhoods? Landsat surface temperature, NDVI and tree cover are summarized for every census tract in Google Earth Engine, joined to ACS data, and tested for disparities with robust regression and Moran's I.

storm-canopy-change

View code →

Maps likely tree-canopy loss after hurricanes such as Helene from Sentinel-2. It corrects for normal seasonal change, reports loss area by county, and includes an area-weighted accuracy assessment following Olofsson et al. (2014).
